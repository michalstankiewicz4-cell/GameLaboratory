GameLaboratory

Game UI

A game's interface as data, over a live scene: menu screens, the HUD, in-game windows and a dialogue box for characters and the narrator. The look is a skin, kept apart from the labs' look: Space, Battle, the engine's, or your own saved under a name. Esc opens the pause screen and closes windows; window keys (I, C, L…) open them.

For AI: GameUIApi in the console (API tab) — load a definition, set the game state, show a screen, say a line.
